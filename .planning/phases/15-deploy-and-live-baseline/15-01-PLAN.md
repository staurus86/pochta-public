<task type="auto">
  <name>Task 4: Compute delta v1→v5 and decide v1.3 priority</name>
  <files>scripts/DELTA.md</files>
  <read_first>
    - scripts/baselines/baseline_v1.json (v1: live-prod pre-v1.1 baseline)
    - scripts/baselines/baseline_v5.json (v5: live-prod post-v1.1 baseline)
  </read_first>
  <action>
    Compare the two baselines and write `scripts/DELTA.md`.

    Compute delta for each field:
    ```python
    import json
    v1 = json.load(open('scripts/baselines/baseline_v1.json', encoding='utf-8'))['fields']
    v5 = json.load(open('scripts/baselines/baseline_v5.json', encoding='utf-8'))['fields']
    for field in v5:
        if field in v1:
            d_present = round(v5[field]['present'] - v1[field]['present'], 4)
            d_noise_free = round(v5[field]['noise_free'] - v1[field]['noise_free'], 4)
            print(f"{field}: present {v1[field]['present']} → {v5[field]['present']} ({d_present:+.4f}) | noise_free {v1[field]['noise_free']} → {v5[field]['noise_free']} ({d_noise_free:+.4f})")
    ```

    Write `scripts/DELTA.md` with:
    1. Delta table (v1 → v5, present% and noise_free% for each field)
    2. Biggest improvements from v1.1
    3. Fields still needing work (lowest noise_free%)
    4. **v1.3 Priority Decision**: the 1-2 fields with lowest noise_free% or biggest gap = top priority

    Use this decision framework:
    - noise_free% < 60% → HIGH priority
    - noise_free% 60-75% → MEDIUM priority
    - noise_free% > 75% → LOW priority (working well)
    - Biggest negative delta → regression to investigate

    Write the decision clearly: "v1.3 должен фокусироваться на: [FIELD] (noise_free X%)"
  </action>
